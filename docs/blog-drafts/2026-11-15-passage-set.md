# Thirteen passages, generated, not typed

The heart of Dhamma Diary is one short passage from the suttas each evening. The first thirteen were chosen weeks ago and signed off one by one. This step turned them into something the app can carry.

None of the text is typed in by hand. A small script reads Bhikkhu Sujato's translations straight from SuttaCentral's open data, picks out each passage by its segment numbers, and writes one file that ships inside the app. It records exactly which version of the translations it read, so any passage can be traced back to its source. The text stays as Sujato wrote it. The one tidy-up: when an excerpt starts partway into a speech, its first line opens a quotation that never closes, so the script removes that one stray mark.

The script is also strict. If two passages share an ID, if a segment range points at nothing, or if a question is missing, it refuses to build. IDs matter because every journal entry remembers which passage it answered, so an ID, once shipped, is never reused.

The order is simple. The first evening you use the app, you get passage one, AN 10.51, "Your Own Mind". The next evening, passage two, whether or not you opened the app in between. After the last passage it starts again. There's no backlog and nothing to catch up on.

Nothing shows on screen yet. Next comes the Diary tab, where the passage, the question and your entry finally meet.
