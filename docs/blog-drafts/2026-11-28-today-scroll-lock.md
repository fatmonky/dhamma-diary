# The press that never let go

Logging a stone is a long press: hold the stone, and the sheet to describe it slides up. Afterwards, Today froze. It wouldn't scroll.

The page turns scrolling off while the stone is pressed, so a slide up or down measures the mind instead of moving the page. It turns scrolling back on when the finger lifts. But the sheet appears while the finger is still down, and the system quietly cancels the press. A cancelled press never "lifts", so as far as Today knew, the stone was still being held.

The fix is to watch the press itself rather than wait for the lift: when the press is gone for any reason, Today lets go too.
